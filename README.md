# OnAim

Images for the WildWin homepage promo widgets (Lucky Wheel, Keys & Chests, Saddle Up & Win Big).

The widget scripts load them through jsDelivr, pinned to a release tag:

    https://cdn.jsdelivr.net/gh/OnAimWW/OnAim@v1/<file>

Do not delete, rename or make this repository private, or the images disappear from the site.
To change an image, upload the new file and create a new tag (v2, v3, ...), then update ASSET_BASE in the scripts.
